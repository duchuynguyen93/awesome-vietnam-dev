## 🤝 Đóng góp

Đóng góp luôn được chào đón! Hãy:

1. Fork repo này
2. Tạo branch mới (`git checkout -b add-resource`)
3. Thêm tài nguyên vào đúng category
4. Commit & Push
5. Tạo Pull Request

**Lưu ý:** Chỉ thêm tài nguyên miễn phí hoặc có tier miễn phí. Đảm bảo link hoạt động.
